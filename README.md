# Лабораторна робота № 4 — дерева рішень та ансамблі на даних із пропусками

**Виконав:** Новак Сергій, ФЕІ-43с. Номер у списку групи $N = 8$, тому `SEED = 42 + 8 = 50`.

Порівняння Decision Tree, Random Forest і XGBoost на датасеті Annealing (OpenML `anneal`, версія 1, 898 спостережень) за наявності великої кількості пропусків:

- аналіз механізму пропусків (таблиці спряженості, перестановочний χ², V Крамера);
- два варіанти обробки в `Pipeline`: імпутація (A) та імпутація + індикатори пропусків (B);
- повторна стратифікована CV 5×3 на однакових блоках;
- підбір гіперпараметрів Optuna (TPE, 30 спроб, внутрішня 3-fold CV) без витоку даних;
- вкладена CV для неупередженої оцінки та порівняння з `best_value`;
- власна реалізація скоригованого t-тесту Наде–Бенжіо;
- фінальна оцінка на тесті, матриці плутанини;
- MDI та permutation importance, аналіз розбіжностей моделей зі SHAP.

## Файли

- `practice_4_annealing.ipynb` — звіт: код, таблиці 1–7, графіки, висновок і контрольні питання;
- `models/` — три фінальні моделі (варіант B, після Optuna), збережені через `joblib`;
- `data/openml/` — локальний кеш датасету з OpenML, тому для запуску інтернет не потрібен;
- `requirements.txt` — точні версії бібліотек (`pip freeze`).

## Запуск

Потрібен Python 3.10+ (робота виконана на 3.12).

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
jupyter notebook practice_4_annealing.ipynb
```

Далі **Kernel → Restart & Run All**. Повний прогін триває близько 9 хвилин, з них приблизно 6 — вкладена CV з Optuna.

## Основні результати

| Модель (варіант B, після Optuna) | вкладена CV, macro F1 | test accuracy | test macro F1 |
|---|---:|---:|---:|
| Decision Tree | 0.9782 ± 0.0146 | 0.9889 | 0.9270 |
| Random Forest | 0.9861 ± 0.0101 | 0.9944 | 0.9326 |
| XGBoost | 0.9868 ± 0.0138 | 0.9889 | 0.9270 |

Індикатори пропусків підвищують macro F1 на 0.055–0.065 для всіх трьох моделей, і ця різниця статистично значуща за тестом Наде–Бенжіо. Різниця між найкращими моделями статистично незначуща.
